# Lab 2 — Neural Network Report

## Objective

The aim of this lab is to understand how a neural network works and how it learns from data.

## How a Neural Network Works

### 1. Forward Propagation

The network takes input data and passes it through its layers to get a prediction.

### 2. Loss Function

The loss function measures how far the prediction is from the correct answer. A lower loss means the prediction is closer to the expected result.

### 3. Backpropagation

During this step, the network calculates how its weights contributed to the error. These calculations help it improve its predictions.

### 4. Optimization

The weights are updated during training to reduce the loss. This process is repeated over several epochs.

### 5. Prediction

After training, the network can use what it has learned to predict the classes of new images.

## Conclusion

In this lab, I learned the main steps of neural network training. The network makes predictions, calculates the error, and updates its weights to improve its results.
