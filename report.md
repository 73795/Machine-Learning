## Objective

The aim of this lab is to learn how a neural network works.

### 1. Forward Propagation

The network processes the input data and makes a prediction.

### 2. Loss Function

The loss shows how far the prediction is from the correct answer.

### 3. Backpropagation

The network calculates how to adjust its weights to reduce errors.

### 4. Optimization

The weights are updated to help the network make better predictions.

### 5. Prediction

The trained network predicts which digit is shown in an image.
